# Oprettelse af leverandøradministratorer 
KMD Supplier Overview er bygget på logikken om, at en leverandøradministrator kan oprette nye leverandøradministratorer der 
enten er i egen virksomhed eller hos de virksomheder der agerer underleverandører til den givne virksomhed.
