# Download ID-kort

*Kun tilgængelig når projektet har ID-klausul 1.*

**1.** Åbn projektet og naviger til projektets medarbejderliste.

**2.** Find medarbejderen og klik på kontekstmenuen til højre og vælg **Download ID-kort**.

![](/img/docx/docx_img_184.png)

**3.** Der vises en meddelelse om, at download af kortet kan tage lidt tid. 

![](/img/docx/docx_img_185.png)

**4.** Efter et kort øjeblik er kortet downloadet til computeren, og kan findes i mappen 'Overførsler'/'Downloads'.

![](/img/docx/docx_img_186.png)

**5.** Når du åbner filen, kan du se ID-kortet. 
![](/img/docx/docx_img_187.png)

:::info[Bemærk]
Filnavnet er 'personnavn-firmanavn.jpg'. På den måde kan du lettere finde det rigtige kort blandt de kort, du har downloadet. 
:::
