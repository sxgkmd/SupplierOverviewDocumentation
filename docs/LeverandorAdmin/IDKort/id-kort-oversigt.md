# ID-kort oversigt
En medarbejders ID kort har flere formål. 
Dels bruges kortet til at identificere sig på byggepladser, dels kan kortet bruges som adgangsnøgle på projekter, hvor der er sat adgangskontrol op. 

ID-kort funktionaliteten afhænger af projektets **ID-klausul**. 
Der findes to **ID-klausuler**.
- Registering af medarbejdere (også benævnt klausul 1)
- Registering af medarbejdere og brug af ID-kort (også benævnt klausul 2)

Som leverandøradministrator har du følgende muligheder på de to ID-klausuler
| Funktion                  | Registering af medarbejdere | Registering af medarbejdere og brug af ID-kort |
|---------------------------|:----------------------------:|:--------------------------:|
| [Bestil ID-kort](bestil-id-kort.md) (til print på ID-kortprinter)           | —                            | Ja                         |
| [Print ID-kort på lokal printer](print-id-kort-lokalt.md)      | Ja                           | —                          |
| [Download ID-kort](download-id-kort.md)         | Ja                           | —                          |
| [Aktiver / Genaktiver](aktiver-genaktiver-id-kort.md)      | —                            | Ja                         |

:::info[Bemærk]
ID-kort printere er specielle printere som kan udskrive plastickort med/uden chip. Printeren er typisk placeret på projektlederens kontor. 
Hovedleverandøradministrator og projektleder kan printe ID-kort direkte og udenom bestillingsflowet. 
:::
