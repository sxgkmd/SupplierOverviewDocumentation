# SMS-notifikationer

Som leverandøradministrator kan du sende SMS-beskeder til medarbejdere:

1. Find medarbejderen i medarbejderlisten.
2. Klik på **Send SMS**.
3. Skriv beskeden.
4. Klik **Send**.

> SMS bruges typisk til at informere medarbejdere om ændringer i projektadgang, ID-kort-status eller påmindelser.
