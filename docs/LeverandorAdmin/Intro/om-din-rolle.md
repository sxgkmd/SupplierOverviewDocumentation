# Om din rolle

Forudsætningen for at kunne logge ind i KMD Supplier Overview er, at du er oprettet som **leverandøradministrator** i KMD Supplier Overview. 
En **leverandøradministrator** er en medarbejder, der er tilknyttet en leverandør hos ét eller flere af bygherrens projekter.

Som **leverandøradministrator** har du ansvar for at administrere din virksomheds medarbejdere, ID-kort og underleverandører inden for de projekter, du er tilknyttet.

Du kan:

| Funktion                                |
|-----------------------------------------|
| Se og redigere virksomhedsoplysninger   | 
| Oprette og redigere medarbejdere        | 
| Fjerne medarbejdere fra projekt/firma   | 
| Bestille ID-kort (ID-klausul 2)         | 
| Printe/downloade ID-kort (ID-klausul 1) | 
| Aktivere og deaktivere ID-kort          |
| Tilføje og fjerne underleverandører     | 

> **ID-klausuler** afgør hvilke ID-kort funktioner der er tilgængelige på et givent projekt. Projektadministratoren konfigurerer dette.
