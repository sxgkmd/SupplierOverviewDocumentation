# Opgaver

Din opgaveliste finder du via fanen **Opgaver** og indeholder:

- **Printgodkendelser** — ID-kort der afventer din godkendelse til print.
- **Dokumentgodkendelser** — dokumenter der afventer godkendelse.
- **Mine processer** - processer/opgaver du tidligere har gennemført. 
- **Kladder** - processer/opgaver du har gemt som kladder og som du ønsker at vente tilbage til.
