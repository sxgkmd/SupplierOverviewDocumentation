# Ofte stillede spørgsmål

### Hvad er forskellen på ID-klausul 1 og 2?

- **ID-klausul 1**: Projektet bruger lokale ID-kort-printere. Du kan printe og downloade ID-kort direkte.
- **ID-klausul 2**: Projektet bruger en API-baseret løsning. Du kan bestille, aktivere og deaktivere ID-kort.

Klausulen sættes af projektadministratoren og bestemmer, hvilke knapper du ser ved medarbejderne.

### Jeg kan ikke se "Nøgletal" — hvorfor?

Nøgletal er kun tilgængelige for rollerne *admin*, *superuser*, *projektadministrator* og *projektleder*. Som leverandøradministrator har du ikke adgang til denne funktion.

### Jeg kan ikke printe ID-kort via API — hvorfor?

API-print (serverbaseret print) er forbeholdt *hovedleverandøradministrator*, *admin*, *projektadministrator* og *projektleder*. Som leverandøradministrator kan du til gengæld printe lokalt (ID-klausul 1) eller bestille ID-kort (ID-klausul 2).

### En medarbejder mangler dokumenter — hvad gør jeg?

1. Du modtager en automatisk e-mail-påmindelse.
2. Log ind på Supplier Compliance.
3. Find medarbejderen under det relevante projekt.
4. Upload de manglende dokumenter via medarbejderens detaljevisning.

### Hvordan tilføjer jeg en udenlandsk underleverandør?

1. Gå til **Underleverandører** > **Tilføj leverandør**.
2. Vælg fanen **Udenlandske virksomheder**.
3. Udfyld virksomhedsoplysninger manuelt (CVR-opslag er kun for danske virksomheder).

### Hvem kontakter jeg ved problemer?

Kontakt din **projektadministrator** eller **hovedleverandør** for projektrelaterede spørgsmål. For tekniske problemer med systemet, kontakt din organisations IT-support.
