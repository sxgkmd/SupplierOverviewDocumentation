# Rediger oplysninger på medarbejder

**1.** Klik på “Leverandører” i topnavigationen og søg på den pågældende leverandør, hvor medarbejderoplysninger skal redigeres

![](/img/docx/docx_img_106.png)

![](/img/docx/docx_img_107.png)

![](/img/docx/docx_img_108.png)

**2.** Klik på medarbejder-fanen og klik på handlingsikonet ud fra den medarbejder, hvis oplysninger skal redigeres.

![](/img/docx/docx_img_109.png)

![](/img/docx/docx_img_110.png)

**3.** Medarbejder-formularen åbnes og **medarbejderens oplysninger kan redigeres.**   
Klik herefter ”gem og opret”

![](/img/docx/docx_img_111.png)

**4.** Handlingen kan ligeledes udføres fra medarbejderens profil og ved klik på redigeringsikonet, som vil åbne medarbejderformularen vist i trin 3.

![](/img/docx/docx_img_112.png)
