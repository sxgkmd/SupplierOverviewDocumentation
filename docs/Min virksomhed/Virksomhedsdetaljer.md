# Virksomhedsdetaljer

### Overblik over virksomhedsdetaljer

Klik på 'Min virksomhed' i toppen af billedet. 

Nu ser du din virksomheds detaljer såsom CVR nummer og adresse øverst på siden. Nederst på siden ser du de medarbejdere, som er oprettet i din virksomhed.
